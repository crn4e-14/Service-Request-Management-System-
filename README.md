# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/bbcb3934-2c13-4bf2-b2ff-ac644bf9e3ad

## Run Locally (Cursor / เครื่องตัวเอง)

**Prerequisites:** Node.js 20+

แอปนี้เป็น frontend จำลองข้อมูลในเบราว์เซอร์ ไม่ต้องใส่ Gemini API key ก็รันได้

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. เปิดเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000)
